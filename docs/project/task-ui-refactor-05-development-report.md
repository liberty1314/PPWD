# TASK-UIR-05 开发记录：桌面密码库与关键工作流

## 结论

桌面 React renderer 已接入密码库、收藏、最近访问和安全中心。密码数据继续通过现有 API、加密转换与安全 store 处理；本任务没有改动持久化 schema、加密格式、preload/IPC 或自动填充协议。实现与自动验证完成，常规及 900px 窄窗口 Electron 真人旅程尚未验收，留到 TASK-UIR-09。

## 实施范围

- 新增共享的密码库/收藏/最近访问工作区，支持关键词搜索、类型筛选、排序、加载与错误恢复、条目选择、窄屏返回、分段显示、批量收藏/取消收藏/删除和确认对话框。
- 支持条目详情、收藏切换、复制与短暂显示敏感字段、编辑、复制条目、删除、CSV 导入/导出，以及登录、服务器、银行卡、身份、安全备注、验证器、数据库、自定义类型表单。
- 保留 TOTP URI 导入、动态验证码和复制；普通条目及自定义条目的验证器扩展字段沿用现有数据结构和 TOTP 工具。
- 新增安全中心，检测登录/服务器/数据库密码的短密码和重复使用；风险项可以跳转至对应条目。
- 将概览统计、最近访问和快捷操作连接至实际路由；接入托盘快速搜索命令。
- 新增弱密码/重复密码审计纯逻辑及测试。React session 不保存保险库明文；页面在锁定门禁切换时卸载，敏感值仍由现有安全 store 和剪贴板策略管理。

基线检查未发现桌面密码库已有附件 schema、API 或界面入口，因此没有新增附件持久化或虚构入口；已有备注字段正常保留。该范围已在开发计划中注明。
