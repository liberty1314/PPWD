## 模块验证记录

### MOD-M2-21：安全存储及 IPC

环境：macOS 与 Windows 桌面包；命令 `pnpm run dev` 或已构建桌面包。测试数据：新建空保险库。当前实际结果与证据：待人工执行。

UI/流程清单：Setup/Bind/Unlock 错误状态；safeStorage 不可用时不得创建或绑定；读取恢复密钥必须再次验证；密钥不得出现在 `vault-data.json`、日志或普通配置文件。

### MOD-M2-22：创建及路由门禁

环境：macOS 与 Windows 桌面包；测试数据：空目录保险库、已创建未绑定保险库、已绑定但锁定保险库。当前实际结果与证据：待人工执行。

UI/流程清单：`/setup`、`/bind`、`/unlock`、`/recover` 直达；未绑定/未解锁访问 `/dashboard`；冷启动重进；自动锁定后桥接不可读；窄窗口、键盘焦点与错误提示。

### MOD-M2-24：换绑及恢复

环境：已绑定的手机验证器；有效主密码与恢复密钥。当前实际结果与证据：待人工执行。

UI/流程清单：旧令牌 + 主密码换绑；换绑前错误码与错误主密码；旧码失效；仅主密码/仅恢复密钥不能恢复；主密码 + 恢复密钥恢复后旧码立即失效；新绑定成功后解锁；查看恢复密钥必须再次输入主密码和动态码，关闭设置后密钥明文消失。

### MOD-M2-25：首次引导

环境：空数据目录；macOS 与 Windows 桌面包。当前实际结果与证据：待人工执行。

UI/流程清单：创建主密码；检查恢复密钥为 128 位 Base64URL；下载 Emergency Kit 并检查无用户名/邮箱、内容完整；确认保存后继续；已有数据目录被阻止并可选择空目录；创建或绑定中退出并重启，回到正确未完成步骤且已存恢复材料可用。

### MOD-M2-26：生物识别快捷解锁

环境：支持 Touch ID 的 macOS 和支持 Windows Hello 的 Windows；当前实际结果与证据：待人工执行。

UI/流程清单：在设置开启“优先生物识别解锁”时输入主密码并完成系统生物识别确认；冷启动与锁定后解锁页均优先生物识别；可切换到 6 位 TOTP 单独解锁；取消生物识别留在当前页，生物识别失败时提示错误并切换到 TOTP；关闭偏好后只显示 TOTP，主密码不提供日常解锁入口。
