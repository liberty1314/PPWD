# BearPassword 桌面端 UI 改版方案

## 设计目标

将桌面端密码库从“功能控件集合”整理为清晰、安静、可信赖的日常工作区。减少玻璃质感、强烈主题色和层层卡片，优先让用户快速找到条目、识别安全状态并完成复制或编辑。

## 原型范围

覆盖当前桌面端全部主要页面与独立窗口：概览、密码库、收藏、最近访问、设置分区、初始化、解锁、恢复、账户绑定，以及快速搜索浮窗。原型采用示例数据，不连接真实保险库。

## 页面结构

- **应用侧栏**：产品标识与主导航（概览、密码库、收藏、最近访问）；底部放置本地保险库状态和设置入口。当前页通过浅蓝选中背景与细色条提示。
- **内容标题区**：页面名称、条目数量、搜索、分类筛选和高对比新增操作集中呈现。
- **双栏密码库**：左侧条目列表保留足够的信息密度；右侧详情区显示站点、用户名、密码遮蔽状态、网址和最近更新时间，主要操作采用图标按钮并提供明确标签。
- **安全提示**：使用低饱和语义色提示风险或健康状态，避免把安全提醒做成抢占注意力的大型彩色卡片。

## EasyUI 视觉映射

- 背景采用近白灰（约 `#fafafa`），面板为白色；分组通过细边框、间距和灰阶区分。
- 主文字使用近黑，描述文字使用中灰；蓝色只用于选中、焦点和主操作。
- 面板圆角约 12–14px，输入和按钮高度统一；阴影仅用于弹层，不让静态面板漂浮。
- 动效只用于 hover、按下和选中反馈，建议 150–220ms，并遵循 `prefers-reduced-motion`。
- EasyUI 目录提供 React + Tailwind/shadcn registry 组件，而该仓库桌面端是 Vue 3 + Element Plus，因此原型参考其视觉与交互准则，不直接引入 React 组件。正式实现优先复用 Element Plus 的 Button、Input、Select、Dropdown、Tooltip、Badge 等 Vue 控件，并统一到中性 EasyUI token。

## 建议优先级

1. 先改造密码库主页面的布局、间距、字体层级和控件状态。
2. 再统一概览、收藏、最近访问、设置弹窗的侧栏与表面规范。
3. 最后检查暗色主题、键盘焦点、窄窗口布局和 reduced-motion 行为。

## 需要产品确认的方向

- 是否以浅色中性主题作为默认主题，保留现有其他主题作为可选项。
- 密码库默认进入双栏详情视图；窄窗口时详情改为独立页面/抽屉。
- 安全健康度、弱密码提示等是否纳入首页或仅作为条目级信息。
